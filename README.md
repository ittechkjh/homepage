# 🚀 CoinHub (Coin Community & Real-Time Market Platform)

> 암호화폐 투자자들을 위한 실시간 시세 분석, 커뮤니티 포럼, 실시간 채팅 및 뉴스 애그리게이터 종합 플랫폼입니다.

---

## 🌟 주요 기능 (Core Features)

### 1. 실시간 마켓 데이터 (Real-Time Market Data)
* **CoinGecko API 연동**: BTC, ETH, SOL, XRP, DOGE 등 주요 암호화폐의 실시간 시세, 24시간 변동률, 거래대금 제공
* **인터랙티브 가격 차트 (Chart.js)**: 24시간, 7일, 1개월 단위의 가격 변동 추이 및 최고가/최저가 실시간 표시
* **시장 심리 지수**: 실시간 탐욕 & 공포 (Fear & Greed) 지표 시각화

### 2. 커뮤니티 토론 포럼 (Community Forum)
* **카테고리별 서브 포럼**:
  * 💬 자유 토론 (General Discussion)
  * 📊 차트 / 기술적 분석 (Technical Analysis)
  * 🚀 알트코인 분석 (Altcoin Analysis)
  * 🪙 ICO / 신규 토큰 세일 (ICO & Token Sales)
  * ❓ 초보 Q&A 코너 (Newbie Corner)
* **게시판 기능**: 게시글 작성, 실시간 댓글 등록, 추천/비추천 투표 시스템, 정렬 필터(최신순, 인기순, 댓글순)
* **로컬 저장소(LocalStorage)** 기반 지속성 지원

### 3. 실시간 트레이더 채팅 (Live Chat)
* 실시간 접속자 및 활성 트레이더 목록
* 실시간 시장 반응 및 아이디어 공유 채팅방

### 4. 암호화폐 뉴스 피드 (News Aggregator)
* 글로벌 주요 블록체인 미디어(CoinDesk, Cointelegraph, Bloomberg 등) 실시간 속보 수집

### 5. 유저 인증 & 프로필 시스템 (User Auth & Profiles)
* 닉네임 기반 회원가입 및 로그인 모달
* 프로필 평판 점수 및 회원 등급(VIP, PRO, Member) 표시

---

## 🛠 기술 스택 (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Styling**: Tailwind CSS CDN, Custom Dark Navy & Cyan Neon Glassmorphism Theme
* **Icons**: Lucide Icons
* **Charts**: Chart.js
* **Data Sources**: CoinGecko Free Public API
